Neon Floor 1986 is a grid-based office infiltration game. Use the keyboard controls described below; current progress is reported in the operator console.

Symbols: the operator has a square helmet, access keys have teeth, drones are diamonds with an eye, and the uplink is a striped terminal marked U.

Field manual

How to play

1. Infiltrate. Start with Enter, Space, Start, or any move key.

2. Recover. Collect all three key-shaped access tokens.

3. Evade. A collision or tile swap with either drone ends the run.

4. Extract. Enter the cyan uplink only after the HUD shows 3 / 3.
